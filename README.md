# Trader Biomass – Inventory & Order Management System

## 🚀 Project Overview

Trader Biomass is a Spring Boot based Inventory & Order Management System designed to manage products, stock operations, and order processing efficiently.

The application simulates real-world inventory handling with secure REST APIs, transaction management, validation handling, and scalable backend architecture.

---

### Backend

- Hibernate

### Database
- MySQL
